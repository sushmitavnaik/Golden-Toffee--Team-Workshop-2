# Instructor-Supplied Course Materials

The scaffold includes two course knowledge sources. Before distributing the final exercise, the instructor also places the spreadsheet and exact business question here and keeps all filenames synchronized with the student case template:

- `source_data.xlsx` — the spreadsheet used to answer the business question;
- `business_question.txt` — the exact business question used to create the baseline chart;
- `Data_Visualization_for_Business_Decisions_Principles.pdf` — the governing framework containing the six dimensions and eighteen elements;
- `From_Pixels_to_Insights_Case_Study.pdf` — the applied case study used only as an illustration and calibration source.

Students treat these files as supplied evidence and do not edit them. The principles document governs the agent's analytical rules. The case study shows how those principles have been applied and where AI recommendations required human judgment; it is not a design template to copy. Each student's baseline chart is created separately in ordinary ChatGPT and stored inside that student's agent folder.

The course-material files are intentionally not part of `FROZEN_CORE_SHA256.txt`, allowing the instructor to insert the final spreadsheet and question without changing the practice architecture. Regenerate `PACKAGE_SHA256.txt` before posting the completed ZIP.
